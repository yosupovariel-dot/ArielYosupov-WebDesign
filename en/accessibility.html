Accessibility Statement

Last updated: August 2026

1. Our Commitment to Accessibility

This website was designed and built with an effort to meet accessibility best practices, aiming to align with WCAG 2.0 Level AA guidelines.

2. Accessibility Features Implemented

An accessibility menu is built into the site (accessible via the floating button), allowing you to increase or decrease text size, switch to high contrast, underline links, and stop animations. The site was also built with attention to semantic structure (properly nested headings, labeled form fields), descriptive alt text for images, and keyboard navigation support.

3. Note on Audit Status

The site was designed and built with accessibility in mind, but as of the date of this statement it has not yet undergone a formal accessibility audit by an external certified party. If you encounter any accessibility issue, we would like to know about it and address it promptly.

4. Accessibility Inquiries

Encountered an accessibility problem or difficulty on the site? Please contact yosupovariel@gmail.com or call +972 55-665-8131, and we will do our best to respond and address the issue as soon as possible.
